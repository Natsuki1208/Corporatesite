# BLOCKOPS Brand Guide

## 品牌核心

- 中文品牌：麥塊智慧維運
- 英文品牌：BLOCKOPS
- 中文標語：一格一格建構，讓企業穩定運行。
- 英文標語：Build Smart. Operate Strong.
- 定位：AI智慧維運、IT基礎架構、資安監控、企業自動化及夜間值班協助。
- 調性：可靠、清楚、冷靜、模組化、有科技感但不冰冷。

## Logo 系統

Logo 由 9 個幾何方塊構成大型 Voxel 立方體，中央為青藍 AI 核心節點。上層使用運行綠、左側使用深色、右側使用青藍與科技藍，底部搭配簡化系統心跳線。圖形是本專案原創抽象幾何，不引用或模仿任何遊戲角色、物件、材質、商標或官方字標。

- `blockops-logo-horizontal.svg`：網站 Header、橫幅與一般使用。
- `blockops-logo-stacked.svg`：方形或直式版位。
- `blockops-mark.svg`：純標誌、Avatar 與大型裝飾。
- `blockops-monochrome.svg`：單色、小尺寸或深色頁尾。
- `favicon.svg`：瀏覽器分頁圖示。

所有 SVG 可縮放、透明背景，並包含無障礙 `title`；複雜標誌另含 `desc`。

## 字體

網站僅使用作業系統內建 UI 字體與等寬字體 fallback，不載入外部 Font，也不模仿 Minecraft 官方字標。中文品牌字標採清晰、現代、非裝飾性的粗體無襯線字。

## 視覺規則

1. 方塊採純色、漸層、線框與抽象電路，不使用遊戲紋理。
2. 不使用角色臉、怪物輪廓、遊戲道具或可識別場景。
3. 動畫以狀態溝通為目的，主要使用 `transform` 與 `opacity`。
4. 任何監控畫面均標示為 `DEMO DATA` 或 `SIMULATED`。
5. 綠色代表正常、青色代表監看、金色代表提示；實際動作永遠顯示為 0。
