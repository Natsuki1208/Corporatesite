# Elias Net｜Controlled AI for Real Work

Elias Net 企業產品網站。品牌定位為「把 AI 安全地接進企業每天的工作」，以 Astro、TypeScript、原生 CSS 與 Canvas 2D 製作。

核心產品：

- Elias Knowledge Hub
- Elias Service Copilot
- Elias Ops Sentinel

所有公開內容均明確區分 Concept、Lab、Pilot 與 Production；目前不宣稱正式客戶成果。

- 公開網站：<https://natsuki1208.github.io/Corporatesite/>
- 中文：`/Corporatesite/`
- English：`/Corporatesite/en/`
- Astro 原始碼：`astro-source/`
- GitHub Pages：由 Workflow 從 `astro-source/` 執行 Check、Build 與 Static QA 後發布 `dist/`
- QA／設計報告：`docs/`

動畫支援鍵盤操作、`prefers-reduced-motion`、Viewport 與背景分頁暫停。聯絡表單只在瀏覽器產生 `mailto:` 郵件草稿，不由網站傳送或儲存內容。
